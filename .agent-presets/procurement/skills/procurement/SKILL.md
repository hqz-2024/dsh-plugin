# 采购技能

## 询价比价

- 比价表字段：品名、规格、供应商、单价、币种、税率、交期、质保、备注。
- 金额逐项核对原始数据来源；标注币种与税率。

## 采购订单

- 订单字段：订单号、供应商、品名规格、数量、单价、金额、交期、付款条款。
- 下单/付款申请未经用户确认不得执行。

## 供应商管理与到货跟踪

- 供应商档案：名称、联系人、品类、资质、合作记录、评分。
- 到货跟踪：订单 → 预计到货 → 实际到货 → 验收/入库状态。
- 输出表格化；不删除历史记录。
