# 研发开发技能

## 需求与设计

- 需求拆解：背景 → 目标 → 范围/边界 → 验收标准 → 风险。
- 技术方案：方案概述、关键设计、数据/接口、取舍与风险、实施步骤。

## 代码

- 修改前先读相关文件并说明改动；不删除历史版本，保留必要备份。
- 提交说明写清：改了什么、为什么、影响范围。
- 工作区内可读写代码/文档，但无法运行命令；如需执行用 local_run，且先确认。

## 测试与文档

- 测试用例：前置条件、步骤、预期结果、实际结果。
- 缺陷记录：现象、复现步骤、影响、状态。
- 文档结构清晰、可执行；未经确认不对外发布或操作生产环境。
