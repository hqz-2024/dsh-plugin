# 生产管理技能

## 生产计划与排产

- 计划表字段：订单/产品、数量、工序、计划开工/完工、负责人、状态。
- 排产变更或影响交期的调整，先确认再执行。

## 物料与 BOM

- BOM 清单：物料编码、名称、单耗、需求数量、库存、缺口。
- 物料数量与库存数据核对原始来源。

## 进度与质量

- 进度表：计划 vs 实际、完成率、异常项。
- 质量记录：批次、检验项、合格数/不合格数、合格率、处理结论。
- 输出表格/图表化；涉及数字引用来源。
