# 财务部共享技能

两个角色共用的部门技能。角色差异（经理可审批、员工不可）由各自的预设提示词约束。

## 报销单审核

- 输入报销单内容时，先提取：申请人、金额、事由、附件凭证、日期。
- 核对项：金额与附件一致、事由与费用类型匹配、日期在报销周期内、无重复报销记录。
- 输出格式：结论（同意/驳回）+ 逐项核对结果表 + 依据。
- 普通财务（无审批权）只能出具"核对意见"，审批结论由经理做出。

## 凭证规范

- 凭证编号格式：`YYYY-MM-NN`（年月+流水号）。
- 借贷平衡校验：录入前核对借贷合计，不等则停止并上报。
- 摘要不得超过 30 字；金额保留两位小数。
- 异常数据（金额不符、科目缺失）立即上报经理并停止操作，不自行修正。

## 输出要求

- 涉及数字一律引用原始数据来源（文件路径/凭证号）。
- 表格化输出；未经确认不得对外发送任何文件。
